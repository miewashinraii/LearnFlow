# LearnFlow
Welcome to the **LearnFlow** project! This project aims to provide students with a centralized platform for managing and tracking tasks assigned by their lecturers. By enabling due date tracking, implementing a notification system for upcoming deadlines, and offering progress monitoring features, the platform aims to enhance students' organizational skills and academic performance.

## Installation

To get started with the LearnFlow project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/miewashinraii/LearnFlow.git

2. Navigate to the project directory:
   ```bash
   cd LearnFlow

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt


## Usage 

To run the application, follow these steps:

1. Use the following command:
    ```bash
    python app.py

2. Open your web browser and go to http://127.0.0.1:5000 to access the application.
